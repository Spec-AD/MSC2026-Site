- **个人 API 密钥**：OAuth 同步时额外 `GET /api/v0/user/token`，提取 `personalApiToken`，用于后续免 OAuth 增量同步

[清音] 修复 CHM 前台 isManager 权限判断 Bug: 2026-04-30 20:57

## 问题

多名 CHM 比赛管理员反馈拥有权限但无法在 UI 上录入预选赛成绩。

## 根因

`TournamentManage.jsx` 第 127 行：
```javascript
const isManager = isAdm || (user.role === 'CHM' && tournament.managers?.includes(user._id));
```
`tournament.managers` 是 populate 后的对象数组（`[{ _id, username, ... }]`），`.includes(user._id)` 用 `===` 比较字符串和整个对象，始终返回 false，导致前端 `isManager=false`，成绩矩阵输入框不渲染。

## 修复

| 文件 | 修改 |
|------|------|
| `client/src/pages/TournamentManage.jsx:127` | `.includes(user._id)` → `.some(m => m._id === user._id)` |
| `client/src/pages/TournamentDetail.jsx` | 三处 `isManager={false}` 硬编码 → `isManager={canManage}` |

## 本质

类型比较 Bug — 对象引用 vs 字符串值比较。后端权限校验（`checkTournamentPermission` / `checkTAPermission`）无此问题。
