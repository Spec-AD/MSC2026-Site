## 3. 最终架构决策（团队对齐结果）

| 决策项 | 结论 |
|:-------|:-----|
| 模式命名 | PureBeat 内部命名 `standard/taiko/catch/mania` |
| 排行榜 stable/lazer | b1.7 固定 `legacy=1`（仅 stable），不做切换 Tab；`availableTypes` 返回 `["stable"]` |
| 响应字段结构 | **全部平铺**，不嵌套 `beatmap` / `user` 对象 |
| 时间字段 | 统一 `playedAt` |
| 同步错误码 | 四种：`token_expired` / `rate_limited` / `network_error` / `api_error` |
| Info 缓存 | 串行查四模式 + 5min 内存缓存 |
| scope 修复 | 绑定时显式 `scope: 'public'` |
