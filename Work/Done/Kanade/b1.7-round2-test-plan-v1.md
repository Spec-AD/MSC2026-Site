## 2. 测试用例 — 详细设计 📋

### 2.1 S1 — 数据正确性（后端）

> **优先级**: P0🔴 + P1🟡
> **依赖**: 琉璃修复 Score/AimSpeed/OD 映射 + 非 Ranked 同步
> **测试方式**: API 自动化

| 编号 | 用例名称 | 端点/操作 | 预期结果 | 归属 |
|:----:|---------|:----------|:---------|:----:|
| S1.1 | **排行榜 score ≠ 0** | `GET /api/osu/leaderboard/1223366?legacy=1` | scores[0].score 为数字且 > 0 | 琉璃 |
| S1.2 | **排行榜 score 字段确认** | 同上 + 确认字段类型 | `scores[i].score` 为 integer，非 string | 琉璃 |
| S1.3 | **OD ≠ 0** | `GET /api/osu/leaderboard/1223366?legacy=1` | `beatmap.od` 为数字且 > 0 | 琉璃 |
| S1.4 | **beatmap 字段完整性** | 同上 | `beatmap` 包含 `od/cs/ar/bpm/totalLength/maxCombo/modeInt` | 琉璃 |
| S1.5 | **Aim/Speed 字段存在性** | `GET /api/osu/map/1223366` 或成绩详情 | 响应包含 `aim` / `speed` 字段（可为 null） | 琉璃 |

### 2.2 S2 — 排行榜后端改造（后端）

> **优先级**: P1🟡
> **依赖**: S1 数据修复完成
> **测试方式**: API 自动化

| 编号 | 用例名称 | 端点/参数 | 预期结果 | 归属 |
|:----:|---------|:----------|:---------|:----:|
| S2.1 | **去 mode 参数后仍正常** | `GET /api/osu/leaderboard/1223366?legacy=1`（无 mode）| 200，mode 自动为标准 | 琉璃 |
